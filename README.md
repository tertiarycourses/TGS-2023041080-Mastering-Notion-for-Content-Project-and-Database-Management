## About This Course

Notion combines documents, wikis, project trackers and databases in one connected workspace. This two-day WSQ course teaches you to run it as a governed **content management system**: implement content policies with owners, verified pages and permissions; post and curate rich, styled web content; maintain web properties and assets in relational databases with views, rollups, formulas and automations; publish to the web and read page analytics; extend Notion with imports, integrations and the Notion API; and use **Notion AI** to write, autofill, answer questions and improve the visitor experience.

It is designed for content managers, marketers, project leads, administrators and anyone who runs a team's knowledge, content or projects. All twelve labs build one connected scenario — **Brightwave Media Pte Ltd**, a Singapore content agency moving its wiki, content operations, client projects and public Help Centre into Notion — so you finish with a complete, working CMS.

## Building the Courseware

Every artifact is generated from one content source so the deck, Lesson Plan, Learner Guide and labs never drift apart.

```bash
bash build/build_all.sh          # labs → deck (+ slide_map.json) → LP → LG (+ MD) → PDFs → page-numbered TOCs
python3 build/build_slides.py    # deck only
python3 build/build_lesson_plan.py
python3 build/build_learner_guide.py
python3 build/build_labs.py      # lab folders, mock data, README, lab.yaml, instruction PDFs
```

Requirements: Python 3 with `python-pptx`, `python-docx`, `openpyxl`, `pypdf`, `matplotlib`, `Pillow`, `PyYAML`, and LibreOffice (`soffice`) for PDF rendering.
